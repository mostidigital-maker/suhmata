# Suhmata

Build a modern, responsive heritage website for a Palestinian village before 1948.

The website must support two languages:

- Arabic (default, RTL)

- English (LTR)

The website should have a premium historical museum style, not a business or corporate look.

Design inspiration:

• Old Palestine before 1948

• Traditional stone houses

• Olive trees

• Vintage paper texture

• Warm beige

• Olive green

• Dark brown

• Sand colors

• Soft gold accents

The website should feel emotional, respectful and elegant.

Use subtle animations only.

Sections:

1. Hero Section

- Large historical background image

- Village logo (placeholder)

- Village name

- Short introduction

- Language switcher

- Navigation bar

2. Association Welcome Message

3. Village History

4. Latest News Preview

5. Upcoming Events Preview

6. Gallery Preview

7. Visitor Stories Preview

8. Location Preview

9. Footer

Create reusable components and a clean folder structure.

Everything should be fully responsive.

Prepare the project for future Admin Dashboard integration.

Do not use dummy corporate content.

Use placeholders describing the future content.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
